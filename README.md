# HINTER DEM PLAN – Website

Fertige statische Band-Homepage für **hinterdemplan.de**.

## Enthalten
- responsive Startseite für Handy/Desktop
- Bandgeschichte und aktuelle Besetzung
- Demo-Song-Liste mit Backstage-PRO-Link
- eingebettetes ROA-Livevideo (YouTube nocookie)
- Galerie mit Lightbox
- großer Booking-Bereich
- Impressum- und Datenschutz-Vorlagen
- 404-Seite, Favicon, robots.txt

## Vor dem Veröffentlichen
1. `impressum.html` mit Name, ladungsfähiger Anschrift und E-Mail ausfüllen.
2. `datenschutz.html` nach Auswahl des Hosters ergänzen.
3. Optional weitere Social-Media-Links, Termine und eine Booking-E-Mail ergänzen.

## Kostenlos veröffentlichen – GitHub Pages
1. GitHub-Konto anlegen.
2. Neues Repository z. B. `hinterdemplan` erstellen.
3. Den **Inhalt dieses Ordners** hochladen.
4. Repository: **Settings → Pages** → Branch `main`, Ordner `/root` auswählen.
5. GitHub zeigt danach die kostenlose Seitenadresse an.
6. Für `hinterdemplan.de`: In Pages unter **Custom domain** die Domain eintragen und beim Domain-Anbieter die von GitHub verlangten DNS-Einträge setzen.

Alternativ funktionieren die Dateien auch auf Cloudflare Pages, Netlify oder praktisch jedem normalen Webhoster.
